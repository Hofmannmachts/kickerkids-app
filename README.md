# WunderWelten

Spielerische Lernabenteuer für Kinder von 5–6 Jahren in Fußball- und Zauberwelt.

## Lokal starten

Node.js 20+, `npm ci`, `npm run build`, `npm run dev`. Der Entwicklungsserver liefert dist aus. `npm test` prüft die Spiellogik.

## Gestaltung 0.6

Ausgewählt wurde der filmische Entwurf mit detailreichen Wasserfall-Landschaften, Goldrahmen, Smaragdgrün und Amethyst. App- und Paketname wurden auf WunderWelten beziehungsweise wunderwelten-app geändert. Technische Kennungen, vorhandene Browser-Spielstände und Backend-Verbindungen bleiben kompatibel.

Die bildfüllende Startszene ist eine generierte Illustration, kein frei begehbares 3D-Level. Schaltflächen, Navigation und Spielhandlungen sind echte HTML-Oberflächen. Die drehbare Figur im Atelier verwendet weiterhin das vorhandene Three.js-Modell; die Startillustration bildet individuelle Outfitänderungen noch nicht ab.

Neues Motiv: assets/art/wunderwelten-cinematic.webp. Mit OpenAI imagegen anhand des vom Nutzer ausgewählten eigenen Designentwurfs erzeugt; keine übernommenen Figuren oder Assets der Inspirationsspiele. WebP ist eine reine Formatoptimierung des Originals. Keine zusätzlichen externen Schrift- oder Grafikdienste zur Laufzeit.

Bezahlung bleibt inaktiv. Geplanter Preis: 3,99 €/Monat über PayPal im Web beziehungsweise Apple In-App-Kauf in einer späteren iOS-App.
